# Workbook digital · Encontro extra de missão e visão · Workshop EI · ONS

Página de cada participante no encontro on-line de 30 de novembro de 2026: o mapa do caminho da EI, as instruções de cada atividade (o mesmo texto dos slides e do quadro do Miro), o registro das respostas por e-mail e código e o botão de dúvidas.

- `python3 build.py` gera o site em `docs/`, publicado pelo GitHub Pages.
- `conteudo.json` traz o conteúdo do encontro; `src/` traz o estilo, os scripts, os ícones, as fotos e as imagens do quadro do Miro.
- O serviço (Google Apps Script) e a planilha privada ficam fora deste repositório. Nenhum dado de participante entra aqui.
